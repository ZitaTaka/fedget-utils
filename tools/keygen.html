暗号化キー生成

WebCrypto API でブラウザ内で鍵を生成します。生成した鍵は保存も送信もされません。ページを閉じる前に必要な鍵を保存してください。

🎲 ランダムキー (シークレット)

API シークレット、セッション鍵、ソルトなどに使えるランダムなバイト列です。

🗝️ 暗号鍵 / 鍵ペア

共通鍵は Raw/JWK、鍵ペアは PEM (SPKI / PKCS#8)・JWK・OpenSSH 公開鍵で出力します。

秘密鍵は暗号化されていない PEM で出力されます。取り扱いに注意し、必要に応じて openssl pkcs8 -topk8 等でパスフレーズ保護してください。
